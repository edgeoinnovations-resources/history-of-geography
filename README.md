# From Songlines to the Cloud — a storymap of the history of geography

An interactive, scroll-driven storymap of *From Songlines to the Cloud*, a six-episode history of geography and spatial thinking written and narrated by Paul Strootman (EdGeoInnovations). The site retells the series in **time** (a non-linear timeline) and **space** (a live MapLibre globe), with the podcast audio and full transcripts as companions.

**Live site:** https://edgeoinnovations-resources.github.io/history-of-geography/

## What is in the repository

| Path | What it is |
| --- | --- |
| `index.html`, `css/`, `js/app.js` | The storymap: map, timeline, scroll steps, audio player, transcript drawer |
| `js/chapters.js` | The narrative: one entry per scroll step with date, place, text, camera view and the features to light up. **Edit this to change the story.** |
| `js/config.js` | Basemap URL, tile sources, audio episode offsets, episode colours, timeline scale |
| `data/places.geojson`, `routes.geojson`, `areas.geojson` | Story features, generated by `scripts/build_data.py` |
| `data/countries.pmtiles` | Natural Earth 1:110m countries as a single PMTiles archive (built by `scripts/build_countries.sh`) |
| `audio/` | The six-episode podcast (mono, 64 kbps) |
| `transcripts/` | Episode scripts (Markdown), loaded into the site's transcript drawer |
| `docs/` | The long-form review the series is based on, research notes and the episode PDFs |

## The stack

Everything is open and free to host; the site is static and needs no build step.

- **MapLibre GL JS 5** for the map and globe projection.
- **OpenFreeMap** `positron` basemap, built from **OpenStreetMap** (© OpenStreetMap contributors, ODbL). No API key.
- **PMTiles** for the country-boundary layer, built with **Tippecanoe** from **Natural Earth** and read by HTTP range requests straight from GitHub Pages.
- **NASA GIBS** Blue Marble imagery for the satellite-era steps.
- **Scrollama** for scroll-driven steps.
- **GitHub Pages** for hosting.

## Editing the story

Each step in `js/chapters.js` looks like this:

```js
{ id: "e2-eratosthenes", ep: 2, year: -240, date: "c. 240 BCE", place: "Alexandria → Syene",
  title: "A stick, a shadow, and the size of the planet",
  text: "…",
  view: { center: [31.4, 27.8], zoom: 5.3, pitch: 35, bearing: 0 },
  show: ["alexandria", "syene"],        // place ids from data/places.geojson
  routes: ["eratosthenes"],              // route ids from data/routes.geojson
  areas: [],                             // area ids from data/areas.geojson
  countries: { key: "ADM0_A3", values: ["EGY"] },   // optional Natural Earth highlight
  raster: "bluemarble",                  // optional imagery fade-in
  projection: "mercator" }               // optional; default is "globe"
```

- `year` positions the step on the timeline (BCE is negative); `date` is what readers see.
- To add a place, route or area, add it to the gazetteer in `scripts/build_data.py` and run
  `python3 scripts/build_data.py data`.
- Audio episode start times live in `js/config.js` under `audio.episodes`. They were detected
  automatically from the pauses between episodes; adjust by a second or two if needed.
- Deep links work: every step updates the URL hash (for example `#e2-mercator`).

## Running locally

Any static server that supports HTTP range requests will do (PMTiles and audio seeking need them):

```bash
npx http-server -p 8080 .
# then open http://localhost:8080/
```

Python's `http.server` does **not** support range requests, so the country layer will not load with it.

## Rebuilding data

```bash
python3 scripts/build_data.py data      # places / routes / areas GeoJSON
./scripts/build_countries.sh            # Natural Earth → PMTiles (needs GDAL + tippecanoe)
```
